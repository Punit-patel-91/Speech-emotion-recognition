TASK 2 - EMOTION RECOGNITION FROM SPEECH

1. Download the RAVDESS SPEECH dataset from the official Zenodo page.
2. Extract the speech WAV files.
3. Copy all WAV files/folders into this project's:
   data/ravdess/
   Subfolders such as Actor_01, Actor_02 are fine.
4. Open this project folder in VS Code.
5. Terminal -> New Terminal.
6. Run:
   python -m venv venv
7. Activate on Windows:
   venv\Scripts\activate
8. Install:
   pip install -r requirements.txt
9. Run:
   python emotion_recognition.py
10. Open outputs/ for the confusion matrix, accuracy/loss graphs, metrics, and saved model.

RAVDESS emotion is read from the filename automatically.
Example: 03-01-05-01-02-01-12.wav -> angry (emotion code 05).
